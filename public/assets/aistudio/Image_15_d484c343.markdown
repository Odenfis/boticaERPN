## Brand & Style

This design system is engineered for high-velocity pharmaceutical environments where accuracy and information density are paramount. The brand personality is **authoritative, clinical, and efficient**, mirroring the reliability required in medical software. 

The aesthetic follows a **Corporate / Modern** approach with a specific emphasis on **Desktop Utility**. It bridges the gap between classic ERP software and modern web standards by utilizing a structured layout that prioritizes data visibility over decorative whitespace. Visual flair is reserved for functional feedback (status indicators and alerts), ensuring that the pharmacist’s focus remains on inventory management and patient safety.

## Colors

The palette is anchored in **Health Green** and **Trust Blue** to evoke a sense of medical professionalism and security. 

- **Primary Health Green (#2E8B57):** Used for primary actions, successful stock confirmations, and "In Stock" indicators.
- **Secondary Trust Blue (#1565C0):** Dedicated to navigation, informational callouts, and secondary system actions.
- **Status Triage:** A strict color-coding system for inventory:
    - **Green:** Healthy stock / Long expiry.
    - **Yellow/Orange (#F57C00):** Low stock / Approaching expiry (within 3 months).
    - **Red (#D32F2F):** Out of stock / Expired.
- **Neutrals:** A range of cool grays are used to create the "Desktop" feel, providing subtle contrast between sidebar menus, table headers, and workspace backgrounds.

## Typography

This design system utilizes **Public Sans** for its exceptional legibility and institutional feel. The scale is optimized for high-density screens where users need to scan long lists of medication names and SKU numbers.

- **Base Size:** The standard body text is set to 15px-16px to maintain readability during long shifts.
- **Numeric Data:** For SKU numbers, quantities, and prices, the system uses a slightly tighter tracking to ensure column alignment in dense tables.
- **Hierarchy:** Clear distinction is made between labels and values. Labels use a smaller, bold, uppercase style to act as "signposts" without competing with the actual data.

## Layout & Spacing

The layout utilizes a **Fluid Grid** system that maximizes the use of horizontal screen real estate, common in pharmacy workstations.

- **Information Density:** Spacing is tight (8px/12px increments) to minimize scrolling. 
- **Grid Structure:** A 12-column system is used for dashboard layouts, but individual modules (like the Point of Sale or Inventory Edit) use a "Sidebar-Detail" split.
- **Table Density:** Row heights are kept to a minimum (standard 40-48px) to allow as many line items as possible to be visible above the fold.

## Elevation & Depth

To maintain a professional, systematic feel, the design system avoids excessive layering. Depth is communicated via **Tonal Layers** and **Low-Contrast Outlines**.

- **Surface Levels:** The main workspace is the lowest level (Neutral Base). Content is housed in white "cards" with a subtle 1px border (#E0E0E0).
- **Shadows:** Use extremely soft, diffuse shadows (0px 4px 12px rgba(0,0,0,0.05)) only for active modal dialogs or floating action menus.
- **Interactive States:** Hovering over a table row or a list item should trigger a subtle background tint change rather than an elevation lift, maintaining the "flat" desktop software efficiency.

## Shapes

The shape language is **Soft (0.25rem)**. This slight rounding provides a modern touch while retaining the structured, space-efficient qualities of sharp-edged desktop software.

- **Components:** Buttons, input fields, and checkboxes use the base 4px radius. 
- **Large Containers:** Main content areas or modal windows may use the `rounded-lg` (8px) variant to distinguish them from smaller UI elements.
- **Status Indicators:** Use "Pill" shapes for inventory status tags to make them instantly recognizable against the rectangular grid of the tables.

## Components

### Tables (Data Grids)
The core of the ERP. Tables must feature sticky headers, zebra-striping (subtle gray/white), and condensed cell padding. Sorting and filtering icons are always visible to aid navigation.

### Large Labeled Buttons
For critical actions like "Complete Sale" or "Add New Batch," buttons are large with high-contrast text. Secondary buttons use an outlined style to prevent visual clutter.

### Status Indicators (Pills)
Status tags use a "Light Background + Dark Text" formula for color-coding. For example, a "Low Stock" pill uses a light orange background with the Warning Orange text to ensure readability while maintaining the color signal.

### Input Fields
Inputs use a "Fixed Label" approach where the label sits clearly above the field, not as a placeholder. This ensures that users don't lose context while filling out complex drug monographs.

### Notification Toasts
Standardized alerts for "Low Stock Threshold Reached" or "Prescription Verified." These appear in the top-right corner, utilizing the primary or warning colors to signal urgency.

### Search Bar
A prominent, full-width search bar with an integrated "Category Filter" is required at the top of all inventory views for rapid SKU lookups.
